## 实测(2026-10-28,codex-cli 0.164,gpt-6.1-sol low)
- 默认沙箱里 Codex 不能 git 提交:`index.lock` 被拒。加 `--add-dir` 指向主仓库的 `.git` 也不行。
  - 所以关掉沙箱的项目,助手按阶段提交;开着沙箱的项目,助手不提交,回报时 `mail.py` 自动存改动快照,全部做完由 lead 提交。
- `--add-dir` 能让 Codex 写工作目录外的信箱文件夹。
- Codex 里一条阻塞 130 秒的命令没有被中断。`mail.py wait` 可以这样等。
- Windows PowerShell 5.1 给命令行程序传参时,提示词里的双引号会把参数拆开。派工脚本改成转义成 `\"`。用管道传提示词会让部分中文变成问号,所以没用。
